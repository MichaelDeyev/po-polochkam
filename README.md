# По полочкам

Программа для Windows, которая наводит порядок в домашнем фотоархиве: раскладывает фото и видео по годам и месяцам, восстанавливает даты съёмки, находит точные копии и похожие кадры и помогает выбрать лучшие.

Работает полностью офлайн — снимки не покидают компьютер.

## Зачем

После нескольких переносов между телефонами, облаками и дисками в архиве остаются тысячи копий, а даты файлов ломаются: снимок 2018 года вдруг показывает 2021. Программа выросла из моей задачи разобрать собственный архив — **67 тыс. файлов, 639 ГБ** — и превратилась в продукт, которым могут пользоваться другие люди.

## Принципы

Главное в программе — безопасность данных:

- **Только перемещение.** Файлы переезжают внутри выбранной папки простым переименованием. Программа ничего не удаляет, не перезаписывает и не меняет содержимое снимков.
- **Сначала план.** Анализ только читает файлы. Диск меняется лишь после явного подтверждения.
- **Всё можно отменить.** Каждая операция пишет журнал. Прерванная операция продолжается по своему журналу, любую завершённую можно откатить.
- **Удаляет человек.** Снимки с пометкой «Убрать» уезжают в `_Удалить`, окончательное решение — за пользователем.
- **Защита от ошибок окружения.** Программа отказывается работать с сетевыми, облачными и системными папками; переживает отключение диска посреди работы (пауза, очередь пометок, продолжение после переподключения).

На моём архиве: более 61 тыс. перемещений без единой ошибки, каждая раскладка проверена сверкой с журналом.

## Возможности

| Раздел | Что делает |
|---|---|
| Анализ и раскладка | Определяет дату съёмки по EXIF и другим признакам, строит план «что куда переедет», раскладывает по `Год\Год-Месяц` |
| Дубли | Находит точные копии и ту же картинку в другом размере или качестве |
| Разбор похожих | Группирует похожие кадры (перцептивные хеши) и даёт быстро выбрать лучшие — мышью или с клавиатуры |
| Без даты | Позволяет вручную указать месяц или год для снимков без надёжной даты |
| История и откат | Все операции и отмена последней из них |

Отдельно обрабатываются скриншоты, Live Photos, сканы старых плёночных фото и правки iPhone (`IMG_E…`).

## Устройство

- **Python 3.12**: локальный HTTP-сервер и UI на HTML/JS в отдельном окне
- **Pillow, pillow-heif, NumPy**: чтение HEIC/JPEG и перцептивные отпечатки изображений
- **ExifTool**: даты съёмки и метаданные
- **PyInstaller + Inno Setup**: сборка в установщик, права администратора не нужны
- Журналы операций в JSONL, повтор и откат по журналу
- Тесты на `unittest`: модульные, сценарные, обрывы диска, установщик

Подробное описание устройства — в [app/README.md](app/README.md), инструкция для пользователя — в [app/Как пользоваться.txt](app/Как%20пользоваться.txt).

## Запуск из исходников

```bat
pip install -r app/requirements.txt
python app/run.py
```

Для определения дат нужен ExifTool в `tools\exiftool-13.60_64`. Сборка установщика описана в [app/README.md](app/README.md#сборка-и-проверка).

## Как сделано

Проект разработан вместе с AI-агентом **Claude Code**. С моей стороны — постановка задачи, архитектура, правила безопасности данных (только перемещение, журнал, откат, план до изменений), база знаний проекта для агента и ревью каждого изменения. Код писал агент по этим правилам, а каждое изменение, затрагивающее реальные файлы, проверялось на копии и сверкой после применения.
