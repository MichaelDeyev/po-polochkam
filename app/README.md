# По полочкам

Программа для Windows 10 и 11. Раскладывает фото и видео по годам и месяцам, находит копии и помогает выбрать лучшие кадры из похожих. Работает без интернета: файлы не покидают компьютер. Распространяется установщиком `По полочкам — установка.exe` без цифровой подписи.

До 07.11.2026 программа называлась «Разбор фото». Служебные папки сохранили старое имя (`_Разбор фото` на диске, `%LOCALAPPDATA%\РазборФото`): в них уже лежат журналы отката, и после переименования старые операции нельзя было бы отменить.

Инструкция для пользователя лежит в [Как пользоваться.txt](Как%20пользоваться.txt). Здесь описано, как программа устроена.

## Главные правила

- **Только перемещение.** Файлы переезжают внутри выбранной папки простым переименованием. Программа ничего не удаляет, не перезаписывает и не меняет содержимое снимков. Иногда меняется только дата файла в проводнике (см. ниже).
- **Сначала план.** Анализ только читает файлы. На диске что-то меняется лишь после того, как человек нажмёт кнопку и подтвердит.
- **Всё можно отменить.** Каждая операция пишет журнал. Отменять можно с последней операции по порядку. Прерванная операция продолжается по своему журналу.
- **Окончательно удаляет человек.** Снимки с пометкой «Убрать» уезжают в `_Удалить`, и удаляет эту папку сам человек.
- **Опасные папки не принимаются.** Программа откажется работать с сетевыми, облачными (OneDrive, Dropbox, iCloud, Яндекс.Диск и другие) и системными папками, с корнем системного диска, с папкой пользователя целиком и с диском, где свободно меньше 300 МБ.

## Разделы программы

| Вкладка | Что делает |
|---|---|
| Папка | Выбор папки через окно проводника Windows и список недавних папок |
| Настройки | Что отделять (скриншоты, короткие видео Live Photos, сканы) и какие альбомы не раскладывать по датам |
| Анализ и раскладка | Анализ, план «что куда переедет» и кнопка «Разложить файлы» |
| Разбор похожих | Группы похожих кадров, пометки «Оставить» и «Убрать» |
| Без даты | Указать месяц или год для файлов из `_Проверить` |
| Итог | Что осталось сделать: `_Удалить`, `_Дубли`, `_Проверить` |
| История и откат | Все операции и отмена последней из них |

Вкладки с первой по шестую пронумерованы в порядке работы. Готовый шаг отмечен галочкой, следующий подчёркнут. Над экраном показывается подсказка «Следующий шаг» с кнопкой. Её выбирает `nextStep()` в `ui/index.html` по состоянию из `/api/state`: идёт ли работа, есть ли анализ, сколько файлов ждут раскладки (`layout_moves`), сколько групп похожих не просмотрено (`review_unseen`), сколько пометок не применено (`review_pending`) и сколько файлов без даты (`undated`). Шаг «Без даты» необязательный, его можно пропустить. Ходить по вкладкам в любом порядке по-прежнему можно.

При первом запуске открывается обучение из пяти шагов. В нём только рисунки, файлы пользователя не используются. Повторить его можно кнопкой «Обучение».

## Что куда переезжает

| Папка | Что в ней |
|---|---|
| `Фото по годам\2019\2019-05\` | Фото с надёжной датой. Имя получает приставку `2019-05-06_101112_` |
| `Видео по годам\`, `Скриншоты\`, `Live Photos по годам\` | То же для видео, скриншотов и коротких видео Live Photos |
| `Сканы старых фото\` | Снимки с плёночных сканеров: у них дата сканирования, а не съёмки. Подпапки сохраняются |
| `_Проверить\` | Файлы без надёжной даты. Подпапки сохраняются |
| `_Дубли\` | Точные копии. В `_Дубли\похожие\` лежат та же картинка в другом размере или качестве |
| `_Мусор\` | Служебные файлы: `._*` с Mac, `Thumbs.db`, `desktop.ini` |
| `_Удалить\` | Снимки с пометкой «Убрать» из разбора похожих |
| `_Разбор фото\` | База анализа и журналы отката. Удалять её нельзя, пока нужна возможность отмены |

Отмеченные альбомы остаются на месте. Из них уходят только точные копии и мусор. Файлы, которые уже лежат в папках программы, при повторном анализе не переезжают.

## Дата съёмки

Источники по порядку: EXIF, дата съёмки видео с iPhone, XMP/IPTC, GPS, имя файла (например, `IMG_20180512_143307`) и дата контейнера видео. Если источники расходятся больше чем на сутки, берётся более ранняя дата: снять раньше, чем файл появился, нельзя, а перезапись при копировании даёт более позднюю.

- **Дата файла в проводнике** как источник не используется: при копировании она часто становится датой переноса.
- **Дни массового переноса** программа находит сама: это дни, когда дата разом переписалась у тысяч файлов. Дата контейнера видео, выпавшая на такой день, не считается.
- **Ненадёжная дата** (дата изменения в EXIF или дата видео в день переноса) не годится для раскладки: такие файлы уходят в `_Проверить`. Её показывают как подсказку на вкладке «Без даты».
- **Дата файла в проводнике заменяется** на дату съёмки при раскладке по годам, если включена настройка «Исправлять дату файла». У файлов, которым дату указал человек, она не меняется: точного дня никто не знает.

## Похожие кадры

- **Точные копии** определяются по совпадению содержимого. Оставляется копия из альбома, с EXIF и вне `_Дубли`.
- **Та же картинка** (уменьшенная или пережатая) определяется по отпечаткам pHash и dHash и уезжает в `_Дубли\похожие`.
- **Группы для разбора** — это кадры одной съёмки: похожие отпечатки рядом по времени, а также сцены, склеенные по цветам кадров. В одной группе не больше 60 снимков.
- **Правки айфона.** Айфон сохраняет отредактированный снимок отдельным файлом: `IMG_E0059` рядом с оригиналом `IMG_0059`. Если оба в одной группе, правка подписана, а кнопка «Убрать правки айфона» (клавиша 0) помечает их «Убрать». Сама программа пометки не ставит. Правило в `iphone_edits()` в `razbor/review.py`.
- **Лучший кадр не подсказывается.** Подсказку по резкости, размеру и пересвету проверили на 907 группах прошлого разбора: человек оставлял подсказанный кадр в 18% групп, а случайный кадр совпал бы в 51%. Выбирают по содержанию. Правки айфона там же убирали в 74% случаев, поэтому для них есть кнопка, но не автоматическая пометка.
- **Непросмотренные группы не трогаются.** Пометки применяются только у тех групп, которые человек открыл. Исключение — решения из загруженного файла разбора (ниже).

## Разбор из файла

Кнопка «Загрузить разбор из файла» на вкладке «Разбор похожих» переносит разбор, сделанный до программы на страницах `Разбор похожих.html` и `Разбор дублей.html` (их делали скрипты из `scripts\`, см. README проекта). Подходят оба вида их файлов: «Сохранить результат» (только изменённые пометки) и «Сохранить весь прогресс» (все фото просмотренных групп). Формат — строки `оставить<TAB>путь` или `убрать<TAB>путь`, путь от корня выбранной папки. Полный путь с той же папкой или с другой буквой диска тоже подходит. Строки с `#` — пояснения.

- **Сначала проверка.** `POST /api/review/import` с `write: false` только считает: сколько снимков нашлось, сколько уже в `_Удалить`, сколько не нашлось (с примерами), сколько групп программы файл покрывает целиком. Человек видит это и соглашается. Только тогда идёт запись (`write: true`).
- **Что записывается.** Пометки идут в `marks`, номера снимков — в таблицу `imported`. Группа программы, где решение из файла есть у каждого снимка, отмечается просмотренной. Группы, покрытые частично, остаются непросмотренными и показываются с пометками из файла.
- **Решения из файла выполняются всегда.** Группы программы не совпадают с группами старых страниц, поэтому `Review.decided()` в конце отдаёт решения по снимкам из `imported`, которые не попали в просмотренные группы. Иначе часть пометок «убрать» никогда бы не применилась.
- **Файлы не переезжают при загрузке.** Перенос в `_Удалить` — обычной кнопкой «Применить» в итогах разбора, с журналом и откатом.
- **Проверено** 08.11.2026 на копии структуры диска E: из 5 403 путей настоящего файла владельца: нашлись все 5 403, применение перенесло 5 403 снимка без ошибок, откат вернул все на место.

## Без даты

Вкладка показывает фото и видео из `_Проверить` по 60 на странице. Подсказки даты:

- **дата из ненадёжного источника**, с предупреждением, что это может быть день копирования;
- **снимок с соседним номером кадра** (например, `IMG_4529` рядом с `IMG_4536`, разница до 30 номеров) с надёжной датой и его миниатюра;
- **год в названии папки**, где лежал файл, например «Поездка 2016».

Человек указывает месяц или только год для одного файла или для отмеченных галочками. Перенос идёт в `<папка вида>\2019\2019-06\` или в `<папка вида>\2019\`, если известен только год. Файлы без указанной даты остаются в `_Проверить`.

## Журналы и откат

Журналы лежат в `<папка>\_Разбор фото\журналы\NNNN-вид.jsonl`, пути в них относительные. Поэтому откат работает и после того, как диск подключили под другой буквой или к другому компьютеру.

Каждое перемещение записывается дважды: намерение до переименования (с исходными датами файла) и факт после него. Отмена идёт в обратном порядке. Она возвращает файлы и их даты, а также убирает пустые папки, которые создала операция. Перед каждой операцией программа проверяет, что файлы на месте, не изменились и места назначения свободны. Если хоть что-то не так, ничего не перемещается.

## Отключение диска и пауза

База (`_Разбор фото\база.sqlite`) лежит на том же диске, что и фото. Раньше при отключении диска программа зависала: запросы к базе падали с «disk I/O error», а окно этого не показывало. С 10.11.2026:

- `App.disk` — `ok`, `gone` (папка пропала, ждём) или `paused` (пауза). Сервер раз в 2 секунды вызывает `App.check_disk()`: заметил пропажу — закрывает базу, папка снова видна — открывает её заново (`_reopen`) и дописывает в базу перемещения, не записанные перед обрывом (`pending_rel`).
- Перед обращением к базе `App.need_disk()`. Без диска запрос получает ответ 503 с полем `disk`, а не 500. `/api/state` при этом отвечает без данных анализа и с `disk`. Готовые миниатюры отдаются и без диска: они лежат на компьютере.
- Окно (`request()` в `index.html`) по ответу с `disk` показывает модальное окно «Диск отключён» и раз в 2 секунды спрашивает `/api/disk`. Кроме того, раз в 3 секунды оно проверяет диск само, даже если человек ничего не нажимает. Пометки (`/api/review/mark`, `/api/check/set`), поставленные без диска, копятся в очереди и уходят по порядку, когда диск вернётся. Потом экран перерисовывается на той же группе (`rv.keepPos`).
- Кнопка «Пауза» в шапке (`/api/pause`) останавливает идущую работу (ждёт до 20 секунд), закрывает базу и показывает окно «Пауза». Пока стоит пауза, программа не держит файлов на диске, и Windows даёт его безопасно извлечь. «Продолжить» — `/api/resume`, только если папка снова видна.
- Если диск вернулся под другой буквой, программа сама его не найдёт. В окне есть «Выбрать папку заново». Очередь неотправленных пометок при этом сбрасывается: в другой папке номера снимков значат другое.
- Работа, прерванная отключением, завершается с текстом «Подключите диск и запустите снова: работа продолжится с того же места».

## Устройство

Программа на Python 3.12. Локальный сервер на `127.0.0.1` со случайным портом и одноразовым ключом, интерфейс — одна страница, которая открывается в отдельном окне Edge (раздел «Окно и иконка»). Сторонних ресурсов нет: страница не грузит ничего из интернета.

Данные самой программы (недавние папки, отметка о пройденном обучении, миниатюры до 2 ГБ, журнал ошибок, профиль окна Edge около 60 МБ) лежат в `%LOCALAPPDATA%\РазборФото`.

## Окно и иконка

Программа открывается в отдельном окне Edge без адресной строки и вкладок (`--app`). Edge есть в каждой Windows 10 и 11, ставить ничего не нужно. Если Edge не найден или задана переменная `RAZBOR_BROWSER=default`, страница открывается в браузере по умолчанию.

- **Свой профиль** `%LOCALAPPDATA%\РазборФото\окно`: история и вкладки человека не смешиваются с программой.
- **Флаги Edge** (проверено на Edge 157). `msImplicitSignin` выключен, иначе Edge сам входит в учётную запись Microsoft из Windows и показывает окно «Данные браузера теперь синхронизируются». Режим InPrivate тоже помогает, но пишет «[InPrivate]» в заголовке. `msEdgeStartupBoost` выключен, иначе после закрытия окна Edge перезапускает себя в фоне. Это внутренние названия Edge: в новой версии Edge их нужно проверить заново.
- **Закрытие.** Каждое окно отзывается серверу раз в 30 секунд (`/api/ping` с номером окна), а при закрытии шлёт `/api/bye`. Когда закрыто последнее окно и 5 секунд нет запросов, программа завершается. Пауза нужна, чтобы программу не закрывало обновление страницы. Если идёт работа или открыто окно выбора папки, программа ждёт их окончания. Окно, которое молчит 3 минуты, считается закрытым.
- **Иконка** — две фотокарточки на полке на оранжевой плитке (выбрана 07.11.2026). `python app\make_icon.py` рисует её заново в `razbor\ui\icon.ico` (размеры от 16 до 256) и `icon.png`; готовые файлы лежат в git. Иконку получают exe, окно и панель задач.

## Версия и отчёт для автора

`build.py` при сборке кладёт в программу `version.json` с датой сборки и коротким хешем коммита. Если в `app` были незакоммиченные правки, к хешу добавляется `+`. Версию видно в окне «О программе». Программа из исходников показывает «версия из исходников».

Там же кнопка «Сохранить отчёт на рабочий стол» (`razbor/about.py`). Отчёт — обычный текстовый файл. В нём:

- версия, Windows, тип диска и файловая система выбранной папки;
- что случилось, если человек описал;
- итоги анализа и список операций с числом файлов;
- последняя работа и её ошибка;
- последние 300 строк журнала ошибок.

Путь к выбранной папке и к профилю пользователя в отчёте заменяется метками, но имена файлов из журнала ошибок остаются. Ошибки самой страницы тоже пишутся в журнал ошибок, не больше 50 за запуск. Для тестов папку отчётов задаёт переменная `RAZBOR_REPORT_DIR`.

Сборка:

```bat
set PYTHONPATH=work/build-tools
python app/build.py
```

В `dist` появляются:

- `По полочкам — установка.exe` — установщик, около 31 МБ. Его и раздают;
- `По полочкам\` — та же программа папкой (exe и `_internal`), её можно запускать без установки;
- `Как пользоваться.txt`.

Флаг `--no-installer` собирает только папку. Если программа из `dist` сейчас запущена, Windows не даст заменить файлы. Тогда собирайте рядом, например в `python app/build.py "dist\Новая версия"`.

## Установщик

Сценарий — [installer/installer.iss](installer/installer.iss), картинки мастера рядом с ним (их рисует `make_icon.py`). Версию и пути передаёт `build.py`. Порядок страниц: приветствие, галочка «Ярлык на рабочем столе» (стоит по умолчанию), «Установить», «Готово» с галочкой «Запустить».

- **Только для текущего пользователя**, в `%LOCALAPPDATA%\Programs\По полочкам`: права администратора не нужны, окна «Разрешить изменения?» нет.
- **Ярлыки:** в меню «Пуск» (программа и «Как пользоваться») и на рабочем столе. Программа видна в «Параметры → Приложения», удаляется оттуда.
- **Новая версия ставится поверх старой** по одному `AppId`. Перед этим старая папка `_internal` стирается целиком.
- **Пока программа работает, ни установить новую, ни удалить её нельзя.** Программа держит мьютекс `PoPolochkam.Running` (`AppMutex`), и установщик просит её закрыть.
- **Удаление** стирает программу, ярлыки и `%LOCALAPPDATA%\РазборФото` (недавние папки, миниатюры, профиль окна, журнал ошибок). Папка берётся из переменной `LOCALAPPDATA`, как и в самой программе. Папки `_Разбор фото` с журналами отката на дисках с фото остаются.
- **Подписи нет.** При запуске скачанного установщика Windows SmartScreen покажет «Система Windows защитила ваш компьютер». Само установленное приложение такого окна не вызывает.

Проверки:

```bat
python app/tests/test_units.py
```

```bat
python app/tests/test_flow.py
```

```bat
python app/tests/test_flow.py --exe "%CD%\dist\По полочкам\По полочкам.exe"
```

```bat
python app/tests/test_folder_window.py --exe "%CD%\dist\По полочкам\По полочкам.exe"
```

```bat
python app/tests/test_installer.py
```

```bat
python app/tests/test_disk.py
```

- `test_units.py` — обрывы при перемещении, защита папок, совпадение отпечатков с библиотекой imagehash, на которой настраивались пороги, команда запуска окна Edge.
- `test_flow.py` — весь путь через HTTP на искусственной папке: анализ, раскладка, разбор, «Без даты», откат всех операций с проверкой, что файлы и их даты вернулись. Затем — что программа завершается только после закрытия последнего окна. С `--exe` проверяет собранную программу без Python в `PATH`; путь к exe нужен полный.
- `test_installer.py` — установщик целиком: тихая установка во временную папку, ярлыки и запись в «Приложениях», `test_flow.py` на установленной программе, отказ удалять запущенную программу, удаление и проверка, что не осталось ни файлов, ни ярлыков, ни данных. На время теста на рабочем столе и в «Пуске» появляется ярлык. Если программа уже установлена на этом компьютере, тест пропускается, чтобы её не удалить.
- Само окно Edge автотест не открывает. После правок в `window.py` его проверяют вручную: окно без адресной строки и без окна про синхронизацию, на панели задач наша иконка, после закрытия окна не остаётся процессов `msedge` с профилем `РазборФото\окно`.
- `test_disk.py` — отключение диска на ходу, по-настоящему: папка подключается буквой через `subst`, «выдёргивается» `subst /D` и подключается снова. Проверяет ответы 503, миниатюры и отчёт без диска, сохранность пометки, паузу (папку с базой можно переименовать — значит, программа её отпустила), паузу во время анализа и открытие папки под другой буквой. Само окно с сообщением проверено вручную в браузере. С `--exe` — то же на собранной программе.
- `test_folder_window.py` открывает настоящее окно выбора папки на несколько секунд, поэтому запускается отдельно.
